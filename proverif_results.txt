CPUS - ProVerif verification results
====================================
Date            : 2026-11-26
Tool            : Proverif 2.00
Models          : cpus_main.pv, cpus_fs.pv, cpus_eph.pv
Assumption      : ID_U is a high-entropy secret known only to the user and the server

How to read the lines
  not attacker(secret...) is true    -> session key stays secret (attacker_p1 = after the leak phase)
  inj-event(A) ==> inj-event(B) is true -> injective agreement: every acceptance matches a distinct peer run
  not event(...) is false            -> the accepting event is reachable (results are not vacuous)

Scenarios
  MAIN : protocol exactly as specified (4 messages)
  FS   : server RQC secret key SK=(x,y) released to the attacker after the sessions
  EPH  : optional extension, fresh ephemeral server KEM key per session;
         SK and stored ID_U both released after the sessions
